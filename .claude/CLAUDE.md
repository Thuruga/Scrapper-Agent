# RPA Crawler  - Catálogo de concorrentes — Claude Context

Crawler de RPA para monitoramento de concorrência: varre os catálogos de e-commerce de concorrentes e extrai dados de produtos de forma estruturada.

## Antes de qualquer mudança

**Sempre** consulte o coding standards do Aramis via MCP do Backstage antes de editar arquivos neste repositório:

- Ferramenta: `backstage_get_coding_standards` (servidor MCP `backstage`)
- Configuração: copie `.mcp.json.example` para `.mcp.json` e troque `bkpat_CHANGE_ME` pelo seu PAT pessoal do Backstage
- **Nunca commite o PAT.**

O coding standards é a fonte de verdade para convenções de código, estrutura de pastas, nomenclatura e padrões de qualidade do ecossistema Aramis.

## Sobre este repositório

Este repositório foi criado a partir do template Backstage **empty-repo** e ainda não tem stack definida. Antes de adicionar dependências ou estrutura:

1. Consulte o coding standards (acima).
2. Verifique se já existe um template específico no Backstage para o tipo de projeto que você quer construir (ex.: `backend-api`, `npm-package`, `connect-template`) — se existir, prefira usar o template específico em vez de este.

## Convenções

- Commits: [Conventional Commits](https://www.conventionalcommits.org/) com escopo quando o domínio for claro
- Branches: `feat/`, `fix/`, `chore/`, `refactor/`, `docs/` a partir de `main`
- PRs obrigatórios para `main`. Nunca commite direto.
- Código: Clean Code + princípios de [refactoring.guru](https://refactoring.guru/) — sem over-engineering.
