## Epics & tasks (as provided)

### Epic 1 — O Cérebro (Motor de IA e Perfil Consultivo)
- Refatorar o pipeline do PyTorch para processamento de tensores em lote (Batching), otimizando a inferência na GPU/CPU.
- Substituir o modelo OpenAI CLIP pelo Google **SigLIP** para maior precisão na leitura de texturas, logos e OCR em imagens de e-commerce.
- Implementar Árvores de Decisão (Decision Gates) rigorosas em substituição às médias lineares no matching, reduzindo falsos negativos em SKUs concorrentes.
- Desenvolver o módulo de **"Diagnóstico de Preço"**: o agente cruza variáveis para justificar alterações (ex.: "Preço base caiu, mas o frete aumentou"), consolidando o perfil consultivo.

### Epic 2 — DevOps e Infraestrutura de Guerra
- Fila de mensageria robusta com **Celery + Redis** para orquestração assíncrona no FastAPI, substituindo BackgroundTasks em memória.
- **docker-compose.yml** definitivo (Postgres, Redis, Workers Celery, Backend FastAPI, Frontend React).
- **Proxy Manager** com proxies rotativos residenciais nos engines (incl. curl_cffi) + fallback 2Captcha/CapSolver para resiliência anti-ban.
- Refatorar **vtex_engine.py** para consumir a API GraphQL (Produto Canônico), reduzindo payload e mimetizando tráfego legítimo de frontend.

### Epic 3 — Regras de Negócio Enterprise
- Rastreador da verdadeira métrica de **Ticket Médio** (quantidade de itens/volume).
- Atualizar **nlp_service.py** com Regex para identificar combos e desconstruir "Kits de 3 itens" → valor unitário real.
- Modelo de ML para risco de **Churn de Produto** e ciclo de vida (queda de preço × quebra de grade: liquidação vs. markdown estratégico).
- Injeção de profundidade de estoque (carrinho com 999 unidades via API) para mapear inventário rival.
- Sistema de rastreamento de **Buy Box** (seller vencedor, variação de preço, SLA de entrega).
- **Trava sistêmica de alertas de Violação de MAP** (Minimum Advertised Price) para lojistas 3P.

### Epic 4 — UX e Relatórios Executivos (Push Analytics)
- Substituir polling no React por **WebSockets/SSE** para notificações em tempo real ao finalizar Jobs do Celery.
- **Dashboard Executivo High-Level**: Market Share (pizza para Buy Box) e Volatilidade semanal (barras).
- CRON de **"Dossiê Executivo"** diário (PDF/Excel) às 08h00 com as "Top 10 Ameaças" do dia.
