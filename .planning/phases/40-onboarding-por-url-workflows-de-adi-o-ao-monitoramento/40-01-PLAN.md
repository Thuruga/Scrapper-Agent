    Create NEW module `backend/services/url_utils.py` per D-08. Module-level only (no class) —
    matches the project's small pure-utility pattern. Imports: `from __future__ import annotations`
    and `from urllib.parse import urlparse, urlencode, parse_qsl, urlunparse` (stdlib only; NO new
    package). Define module-level `_TRACKING_PARAMS = frozenset({"utm_source","utm_medium",
    "utm_campaign","utm_term","utm_content","utm_id","gclid","fbclid","msclkid","dclid"})`.
    Implement `normalize_url(url: str) -> str` that: strips input; forces scheme to `https`;
    lowercases netloc and strips a leading `www.` (use a real `www.`-prefix strip, NOT
    `str.lstrip("www.")` which strips the char-set {w,.}, corrupting hosts like `wwww` or any host
    starting with those chars — strip only the literal `"www."` prefix); returns the original `url`
    unchanged if the resulting host is empty (malformed input); sets path to `parsed.path.rstrip("/")`
    or `"/"` if empty; filters query params keeping order, dropping any key in `_TRACKING_PARAMS`
    OR any key whose lowercase starts with `utm_` (both checks — composite + prefix per the
    Anti-Pattern note); rebuilds via `urlencode(filtered_qs)` and
    `urlunparse((scheme, host, path, "", query, ""))`. KEEP all non-tracking path+query so distinct
    SKUs differing by `?skuId=` are NOT merged (D-08). Module-level logger optional.
  </action>
  <verify>
    <automated>cd backend && python -c "from services.url_utils import normalize_url; assert normalize_url('https://www.example.com/p?utm_source=x&skuId=123')=='https://example.com/p?skuId=123', normalize_url('https://www.example.com/p?utm_source=x&skuId=123')"</automated>
  </verify>
