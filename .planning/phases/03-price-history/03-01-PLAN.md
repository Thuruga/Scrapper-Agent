# Plan 03-01: Price History & Monitoring

Implementar persistência de preços para visualização de histórico com gráficos no frontend, garantindo que o serviço de monitoramento utilize a abstração de motores (`BaseEngine`).

## Context
Atualmente, o `PriceMonitorService` já registra mudanças de preço, mas está acoplado à VTEX e não exibe esses dados visualmente (gráficos). Esta fase profissionaliza o monitoramento.

## Proposed Changes

### 1. Refatoração do Serviço de Monitoramento
- Modificar `services/price_monitor_service.py`:
  - Usar `EngineFactory` para obter o motor correto com base na marca.
  - Chamar `get_product_details` do motor abstrato.
  - Garantir que o histórico armazene `timestamp` e `price`.

### 2. Frontend - Visualização em Gráfico
- Modificar `frontend/src/App.tsx`:
  - Instalar e integrar `recharts`.
  - Criar componente `PriceHistoryChart`.
  - Adicionar botão "Ver Histórico" na `MonitorPage` que abre um modal com o gráfico.

### 3. Persistência
- Garantir que `data/price_monitors.json` salve corretamente a lista de `history`.

- [ ] Teste unitário simulando mudanças de preço em `tests/test_price_monitor.py`.
- [ ] Verificação manual do gráfico no frontend com dados reais/mockados.
