<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine result -> provider | Product URL and metadata flow from scraped storefront data into outbound provider calls. |
| provider -> live store | External HTTP with CEP and product identity. |
| provider result -> UI model | External data becomes `ShippingInfo` and primary fields. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-05 | SSRF | Provider product URL | mitigate | Validate URL host against persisted brand domain before outbound calls. |
| T-41-06 | Information Disclosure | Provider logging | mitigate | No CEP/full payload in info/error logs. |
| T-41-07 | Denial of Service | Inline freight fan-out | mitigate | Only with CEP/include flag; bounded concurrency/timeouts; per-product exception absorption. |
| T-41-08 | Tampering/Data Integrity | Rate normalization | mitigate | Parse price carefully; distinguish 0.0 from None; sort options deterministically. |
| T-41-09 | Regression | VTEX path | mitigate | Resolver excludes VTEX real provider; run Phase 33 tests. |
</threat_model>
