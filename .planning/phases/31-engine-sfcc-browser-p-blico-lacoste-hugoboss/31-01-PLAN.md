<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SFCC storefront → parser | Scraped HTML/JSON-LD is untrusted input; crosses into `sfcc_parser.py` |
| visible price text → float | Accessibility/ARIA numbers are attacker-influenceable noise that must not become a price |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Tampering | `parse_pdp` parsing scraped HTML/JSON-LD | mitigate | BeautifulSoup `.get_text()` extracts text only; JSON-LD parsed via `json.loads` as data (never `eval`/exec); malformed JSON swallowed via try/except (V5 Input Validation) |
| T-31-02 | Tampering | `parse_price_br` / `extract_price` price extraction | mitigate | `_BR_MONEY_RE` requires `R$` currency prefix + `,dd` decimal — bare accessibility numbers (e.g. "5 out of 5", "208 reviews") never match (Spike 006 pitfall) |
| T-31-SC | Tampering | npm/pip/cargo installs | accept | No new packages introduced this phase; all deps (beautifulsoup4, playwright, pydantic) already pinned in backend/requirements.txt — no install task, no new supply-chain surface |
</threat_model>
