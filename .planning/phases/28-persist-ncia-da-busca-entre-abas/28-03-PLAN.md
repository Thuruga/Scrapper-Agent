<objective>
Migrar `SearchPage` e `CrossMarketplacePage` de `useState` local para o `useSearchStore` (criado no Plan 02), de modo que o estado de busca sobreviva ao unmount causado pela troca de aba (`AnimatePresence mode="wait"` com `key={activeTab}`, App.tsx:2127-2137, que permanece intacto por D-07). Depende do Plan 01 (que já editou `App.tsx` — ownership exclusivo de `App.tsx` força este plano para Wave 2) e do Plan 02 (o store `useSearchStore` e o `signal` no client precisam existir).

Migram para o store (D-03): Comparativa → `query`, `sort`, `inStock`, `zipcode`, `selectedBrands`, `results`, `loading`. SKU → `targetSku`, `zipcode`, `results`, `selectedItems`, `selectionMode`, `loading`. NÃO migram (permanecem `useState` local — UI transiente): `historyRefreshKey`, `exporting` (ambas as páginas), `loadingShipping` (SKU). A função utilitária pura `withDisplayOrder` permanece local.

Plano com checkpoint: a entrega só é verificável por UAT manual (sem framework de teste no frontend — 28-VALIDATION.md), então inclui um `checkpoint:human-verify` cobrindo os 4 critérios.
