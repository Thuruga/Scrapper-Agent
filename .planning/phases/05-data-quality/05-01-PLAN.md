# Plan 05-01: Data Quality Gates

Integrar uma camada de validação robusta no `BaseEngine` para garantir que apenas dados de alta qualidade (preços válidos, imagens presentes, etc.) cheguem ao usuário, barrando anomalias logo na saída da extração.

## Context
O usuário decidiu adiar a integração de banco de dados para focar na qualidade dos dados extraídos. Atualmente, o sistema pode extrair produtos com preço zero ou sem imagem se o motor de e-commerce retornar dados incompletos.

## Proposed Changes

### 1. Core Validation (Pydantic)
- Modificar `core/models.py`:
  - Adicionar validações ao `RawProductBronze`.
  - Usar `field_validator` para garantir `price_full > 0`.
  - Garantir `image_url` não é nulo.

### 2. BaseEngine Validation Layer
- Modificar `services/engines/base_engine.py`:
  - Adicionar método `validate_result(self, product: RawProductBronze) -> Optional[RawProductBronze]`.
  - Adicionar método `filter_results(self, products: List[RawProductBronze]) -> List[RawProductBronze]`.
  - Integrar `emit_log` para avisar quando um produto for descartado por qualidade insuficiente.

### 3. Engine Integration
- Modificar `services/engines/vtex_engine.py` e `services/engines/shopify_engine.py`:
  - Chamar `self.filter_results` antes de retornar os dados em `run_bulk_scrape`.
  - Chamar `self.validate_result` em `get_product_details`.
