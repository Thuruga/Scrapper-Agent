<objective>
Build the deterministic, HTTP-free foundation for VTEX checkout shipping: a pure parser module (`backend/services/vtex_shipping.py`) plus the additive model evolution in `backend/core/models.py`, both driven test-first by `backend/tests/test_vtex_shipping.py`. Scope is VTEX brand sites only — SFCC/Wake/Shopify/marketplaces are out of this path (D-03).

Purpose: Lift the fragile inline SLA logic out of `_fetch_shipping` (which today does an unfiltered `min(price)`, hardcodes seller "1", drops the estimate unit, and collapses every failure into "Indisponível") into deterministic functions that pickup-filter, convert cents→reais correctly, preserve estimate units, sort by price-then-duration, and classify result states. This is the contract Wave 2 wires into the live HTTP path. Establishes FRET-05's unit contract (centavos→reais) with the R$1.000 unit-regression guard, and mitigates T-33-04 (untrusted SLA payload) by validating types/cents/units/channel before constructing Pydantic models.

Output: New pure-helper module, extended `ShippingInfo`, additive `shipping_options` field on `SearchProductResult`, and a new passing pure-unit test file.
</objective>
