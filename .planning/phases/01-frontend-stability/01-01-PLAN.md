# Plan: 01-01 - Frontend Stability Fixes

**Phase:** 01 - Stabilization & Core Intelligence
**Goal:** Corrigir o reload indesejado na submissão de formulários e melhorar o feedback de monitoramento.

## Context
O usuário reportou que ao clicar no botão de monitorar, a página reseta. Isso indica uma falha na captura do evento de submissão ou um efeito colateral de renderização. Além disso, o uso de `alert()` interrompe a experiência do usuário.

## Proposed Changes

### [Frontend]
#### [MODIFY] [App.tsx](file:///c:/Users/arthur.correia/Documents/Pessoal/scrapper/frontend/src/App.tsx)
- Adicionar `type="button"` em todos os botões que não devem submeter formulários.
- Implementar um sistema simples de `StatusBanner` dentro do `GlassCard` para substituir `alert()`.
- Refatorar `handleSubmit` para garantir que `e.preventDefault()` seja respeitado e que o estado de `loading` seja limpo corretamente.

#### [MODIFY] [App.css](file:///c:/Users/arthur.correia/Documents/Pessoal/scrapper/frontend/src/App.css)
- Adicionar estilos para o novo `StatusBanner`.
