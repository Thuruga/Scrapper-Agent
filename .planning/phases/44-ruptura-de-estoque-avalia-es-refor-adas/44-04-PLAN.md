<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API caller -> review action | Caller can choose monitor_id, scan_product_id, and max_pages only. |
| provider response -> persisted comments | External provider payloads are untrusted and may contain large or unexpected fields. |
| normal search -> review summary | Search must keep summary-only provider calls and avoid comment payload collection. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-14 | Information Disclosure | review provider payloads | mitigate | Normalize to `ReviewComment` fields only; do not persist raw provider payloads. |
| T-44-15 | Denial of Service | review pagination | mitigate | Cap pages by `settings.MAX_REVIEW_PAGES`; route accepts no unbounded page/limit values. |
| T-44-16 | Tampering | review product identity | mitigate | Use `review_product_id` from persisted scan/search product data; route accepts no product_id override. |
| T-44-17 | Spoofing / Access Control | review endpoint | mitigate | Endpoint lives in `routes_monitor.py`, already included under the authenticated API router with `X-API-Key`. |
| T-44-18 | Repudiation | unsupported providers | mitigate | Return and persist `reviews_state="unsupported"` for brands without configured provider support. |
</threat_model>
