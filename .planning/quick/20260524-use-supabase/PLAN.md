# Configurar uso do Supabase Localmente

**Contexto**: O usuário solicitou que o ambiente de desenvolvimento passe a consumir as marcas do banco de produção (Supabase) para resolver a divergência de dados com o `brands.json`.

**Passos**:
1. Adicionar `SUPABASE_URL` e `SUPABASE_KEY` no `.env`.
2. O usuário precisa fornecer essas credenciais.
3. Testar a conexão local.
4. Concluir a task rápida no `STATE.md`.
