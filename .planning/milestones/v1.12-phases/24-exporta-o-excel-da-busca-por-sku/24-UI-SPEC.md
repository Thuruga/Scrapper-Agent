## Interaction Contract

### Selection state machine

| State | Trigger | Visual result |
|-------|---------|---------------|
| Nothing loaded | Results `null` | No toolbar, no checkboxes |
| Results loaded, 0 selected (initial) | Results set | Toolbar visible; all checkboxes unchecked; counter "0 selecionado(s)" (muted); "Apenas selecionados" disabled |
| User checks one card | Card `onClick` with stopPropagation | That card border/bg changes to selected style; counter becomes "1 selecionado(s)" (success color) |
| User checks all cards individually | N checkboxes checked | Select-all toggle turns `.active`; counter "N selecionado(s)" |
| User clicks "Selecionar todos" (unchecked state) | All items selected | All card checkboxes checked; select-all toggle `.active`; counter = total |
| User clicks "Selecionar todos" (checked state / all selected) | All items deselected | All card checkboxes unchecked; select-all toggle inactive; counter "0 selecionado(s)" muted |
| User unchecks one card from all-selected | That card unchecked | Select-all toggle goes inactive; counter decrements |
| User clicks "Exportar Excel" | Dialog opens | Modal overlay; two option buttons |
| User clicks "Todos" in dialog | Calls export with all items | Dialog closes; export button shows spinner; sonner error toast on failure; browser download on success; selection preserved |
| User clicks "Apenas selecionados" (N > 0) | Calls export with selected items | Same as above but with subset |
| User clicks "Apenas selecionados" (N = 0) | Disabled — no action | Button is disabled; no click handler fires |
| User clicks modal overlay or "Manter seleção" | Dialog closes | No export triggered; selection preserved |
| New search submitted | Results replaced | Selection state reset to empty `Set` |

### stopPropagation contract

Every interactive element added inside the `<a>` card (checkbox label) MUST call:
```ts
e.preventDefault();
e.stopPropagation();
```
to prevent the card's anchor navigation from firing.

### State management

Follow `toggleBrand` / `selectAllBrands` / `clearBrands` pattern (App.tsx lines 634–646). Use `useState<Set<string>>` keyed on item URL (unique identifier per result). Example:

```ts
const [selectedItems, setSelectedItems] = useState<Set<string>>(new Set());

const toggleItem = (url: string) =>
  setSelectedItems(prev => {
    const next = new Set(prev);
    next.has(url) ? next.delete(url) : next.add(url);
    return next;
  });

const selectAll = () =>
  setSelectedItems(new Set(allItems.map(i => i.url)));

const clearAll = () =>
  setSelectedItems(new Set());
```

Reset `selectedItems` to `new Set()` when a new search is started (`setResults(null)` path).

## Feedback States

| Scenario | Feedback mechanism |
|----------|--------------------|
| Export in progress | Export button: icon swaps to `<RefreshCw size={16} className="animate-spin" />`, label "Exportando...", button disabled |
| Export success | Browser triggers file download (Content-Disposition attachment); no toast on success |
| Export failure | `toast.error("Erro ao exportar: " + errorMessage)` via sonner; button returns to idle |
| 0 items submitted to backend | Backend returns HTTP 400; frontend catches and shows error toast "Erro ao exportar: nenhum produto para exportar" |
