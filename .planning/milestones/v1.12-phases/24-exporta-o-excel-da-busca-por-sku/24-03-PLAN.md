## Trust Boundaries

| Boundary | Description |

| browser DOM → fetch | User-selected items serialized client-side and POSTed to the export endpoint |
| fetch response → file system | Server-streamed blob written to the user's Downloads via an object-URL anchor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-F1 | Tampering | card `<a>` navigation hijack | mitigate | checkbox `<label>` onClick calls `preventDefault()` + `stopPropagation()` so toggling never navigates (Pitfall 2); verified in human-check step 2 |
| T-24-F2 | Information Disclosure | filename hidden by CORS | mitigate | backend sets `Access-Control-Expose-Headers: Content-Disposition` (Plan 02); client reads it; verified in human-check step 5 |
| T-24-F3 | Tampering | object-URL leak | mitigate | `window.URL.revokeObjectURL(url)` + `removeChild(a)` after click (cloned from exportSearch) |
| T-24-F4 | Spoofing | unauthenticated export call | mitigate | client sends `X-API-Key: API_KEY` header; backend enforces verify_api_key |
| T-24-SC | Tampering | npm/pip/cargo installs | accept | No new packages (24-RESEARCH §Package Legitimacy Audit). lucide-react / sonner / React 19 pre-installed & verified |
</threat_model>
