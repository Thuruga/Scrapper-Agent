## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> backend route | User-provided `brand_key`, `product_url`, CEP. |
| backend route -> provider | Validated brand/product data becomes outbound provider request. |
| provider response -> frontend | External shipping options become UI state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-10 | SSRF | `/calculate-shipping-brand` product_url | mitigate | Require persisted brand, parse URL, host must equal persisted domain or allowed subdomain; test provider not called on mismatch. |
| T-41-11 | Information Disclosure | API logs/errors | mitigate | Do not log CEP or full provider payload. |
| T-41-12 | Data integrity | Unsupported UI state | mitigate | Unsupported/temporary states never set free badge; tests and UI source review. |
| T-41-13 | Regression | VTEX endpoint | mitigate | Leave endpoint in place and run VTEX contract tests. |
| T-41-14 | UX confusion | Mixed product/freight price | mitigate | Keep freight as separate line/options; no mandatory landed total highlight. |
</threat_model>
