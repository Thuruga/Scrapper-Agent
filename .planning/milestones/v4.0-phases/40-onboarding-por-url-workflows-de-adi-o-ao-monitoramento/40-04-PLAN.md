<objective>
Deliver marketplace toggles (UX-05). Promote Mercado Livre / Netshoes / Amazon to REAL entries in
`brands.json` with `is_active` (D-10), reusing the existing `PATCH /brands/{key}/active` chokepoint
(the runtime injection was already removed from `list_brands` in Plan 02). Then enforce activation
PER REQUEST: refactor `CrossMarketplaceService` so its participant engines are selected each call
from `brand_service.list_brands(active_only=True)` (D-11) — deactivating a marketplace excludes it
from the very next cross-marketplace search without a server restart. Keep engine instances as
stateless singletons (verified safe: each marketplace engine opens its own `AsyncSession` per
method, holds no session state on the instance) and preserve a `_by_display` map so
`_enrich_pdp_and_shipping` keeps working.

CRITICAL second bypass found in code review: `factory.py::search_all_brands` (l.87-89) ALSO
hardcodes `target_brands.extend(["mercado_livre","netshoes","amazon"])`, which would re-include a
deactivated marketplace in the REGULAR brand search and silently defeat the toggle. This plan
removes that hardcoded extend so the toggle is honored on both the cross-marketplace AND the regular
search path — single source of truth = `list_brands(active_only=True)`.

Purpose: One activation chokepoint (`is_active`) governs every marketplace, no parallel mechanism.
Output: brands.json entries; per-request enforcement in cross_marketplace + factory; extended tests.
</objective>
