<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /brands/identify | Operator pastes an arbitrary URL string that the server then fetches (detect_engine home fetch) |
| server → external site | detect_engine issues an HTTP GET to the pasted host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-SSRF | Info Disclosure / Spoofing | identify_brand → detect_engine fetch | mitigate | Validate scheme ∈ {http,https}; reject RFC1918/loopback/link-local/reserved IP-literal hosts and `localhost` via stdlib `ipaddress` BEFORE fetch; HIGH severity — blocking gate, covered by `test_identify_rejects_ssrf` |
| T-40-V5 | Tampering | IdentifyRequest body | mitigate | Pydantic-typed body; dry-run never persists (no write side-effect); covered by `test_identify_returns_engine_and_name` asserting add_brand not called |
| T-40-RDR | Spoofing | detect_engine home fetch | mitigate | Existing `allow_redirects=False` (T-25-01-SR) preserved through refactor — a malicious redirect cannot point the fetch at an attacker host |
| T-40-SC | Tampering | npm/pip/cargo installs | accept | No new packages — beautifulsoup4/aiohttp/fastapi already in requirements.txt (RESEARCH Package Legitimacy Audit: zero new deps); `ipaddress`/`urllib.parse`/`json`/`re` are stdlib |
</threat_model>
