## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API client → /search/calculate-shipping-matrix | Untrusted brand_key + product_url cross into the matrix orchestrator |
| Matrix orchestrator → resolver → marketplace/brand hosts | 5 outbound calls per request (one per CEP) |
| Live-scan/search code → matrix module | Boundary that MUST NOT exist (D-10 guard) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Spoofing/Tampering (SSRF) | product_url in the matrix route + per-CEP provider calls | mitigate | Route validates `is_url_allowed_for_brand(request.product_url, brand)` (400 on mismatch) before any matrix call; providers re-validate per Plan 01. Covered by test_calculate_shipping_matrix_rejects_host_mismatch. |
| T-42-02 | Information Disclosure | CEP in matrix throttle/cache/error logs | mitigate | regional_matrix.py logs region labels, never raw CEP (Phase 41 D-21). |
| T-42-03 | Access Control | New /search/calculate-shipping-matrix route | mitigate | Route lives under the /search prefix, inheriting the existing X-API-Key (INTERNAL_API_KEY) middleware; no new bypass. |
| T-42-05 | Tampering (cache poisoning) | (product-identity, cep) cache key | mitigate | Product-identity half is `normalize_url(...)` (drops utm_/tracking params, forces https, strips www.) so tracking-param variants of the same URL hit the same entry and cannot fragment/poison the cache. |
| T-42-06 | Denial of Service (self-inflicted) | Matrix guard bypassed and triggered inline during a large category scan (N products × 5 CEPs) | mitigate | Primary mitigation is the D-10 `triggered_by` guard (raises on non-on-demand trigger) plus the static regression test asserting neither cross_marketplace_search nor run_category_scan reaches the matrix module. |
| T-42-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages (RESEARCH.md Package Legitimacy Audit: "Not applicable"). No install task; no legitimacy checkpoint. |
</threat_model>
