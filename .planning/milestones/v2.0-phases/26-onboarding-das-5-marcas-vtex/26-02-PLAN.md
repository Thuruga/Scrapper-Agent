<objective>
Create `scripts/onboard_vtex_brands.py`: an idempotent seed script that onboards the 5 confirmed VTEX competitor brands (Levi's, Calvin Klein, Zapalla, Austral, Track & Field) by orchestrating the EXISTING flow — `create_brand`-equivalent engine reconfirmation → `discover_categories` → auto-match → `update_mappings`. The script invents no new business logic; it delegates to the service/engine layer and adds only the name auto-match (D-09).

The plan must verifiably defuse the three RESEARCH landmines:
1. The `add_brand` upsert bug (it updates only `domain`/`brand_name`, never `engine`/`is_active`) — the script re-checks `detect_engine` after `add_brand` and force-corrects stale `engine`/`is_active` + `_save`.
2. `vtex_fq_path` must be a RELATIVE path — `_flatten_vtex_tree` returns full URLs, so the script extracts `urlparse(item["path"]).path` before building each `CategoryMapping` (Pitfall 3/5; mirrors the `bck` mappings shape).
3. Austral (`secure.austral.com.br` likely redirects under `allow_redirects=False`) — the script retries `www.austral.com.br` then `austral.com.br` then `secure.austral.com.br` until `detect_engine` reconfirms `"vtex"`; `"unknown"` is rejected as a final state (D-11), and manual override to `"vtex"` is forbidden.

Purpose: deliver COMP-01 — the 5 brands cadastradas with verified engine and core canonical category mappings, ready for search/monitoring and the Phase 29 diagnostic.
Output: `scripts/onboard_vtex_brands.py` (idempotent, dual-persistence, re-runnable).
</objective>
